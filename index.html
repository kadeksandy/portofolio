Tentang saya

Saya adalah seorang pengembang sistem dan web yang memiliki dedikasi tinggi dalam menciptakan solusi digital inovatif berbasis teknologi modern. Saat ini, saya sedang menempuh pendidikan di ITB STIKOM Bali, setelah sebelumnya membangun fondasi teknis yang kuat di SMK TI Bali Global Jimbaran.

Keahlian utama saya terletak pada pengembangan aplikasi menggunakan framework Laravel untuk kebutuhan backend yang terstruktur, serta perancangan antarmuka pengguna (UI/UX) yang intuitif melalui Figma. Saya memiliki pengalaman nyata dalam mengelola siklus pengembangan perangkat lunak secara menyeluruh, mulai dari perancangan sistem, implementasi kode, hingga tahap pengujian.

KEAHLIAN TEKNIS

Keahlian & Pengalaman Teknis

Saya memanfaatkan Figma untuk merancang antarmuka pengguna dan pengalaman pengguna, mencakup perencanaan tata letak (layout), alur navigasi, hingga desain visual. Pengalaman ini mengasah kemampuan saya dalam menerjemahkan kebutuhan pengguna menjadi rancangan yang fungsional, konsisten, dan siap diimplementasikan ke tahap pengembangan perangkat lunak.

Dalam pengembangan aplikasi web, saya mengandalkan framework Laravel dengan fokus pada manajemen basis data yang efisien dan logika bisnis yang sistematis. Saya terbiasa membangun sistem pendukung operasional yang memiliki struktur sisi backend yang rapi, andal, serta mudah untuk dikembangkan lebih lanjut maupun dipelihara.

Saya menguasai HTML, CSS, dan JavaScript sebagai pilar utama dalam membangun fondasi website. Fokus saya pada implementasi desain yang responsif di berbagai perangkat, serta menciptakan interaksi pengguna yang dinamis.

Saya memiliki pengalaman dalam mengeksplorasi dan mengimplementasikan payment gateway khususnya Xendit untuk memfasilitasi transaksi digital dalam aplikasi. Proses ini telah melatih kemampuan saya dalam memahami alur autentikasi API, penanganan callback, serta sinkronisasi status pembayaran guna menjamin integritas data transaksi dalam sistem.

Saya mampu mengembangkan fitur notifikasi secara real-time dengan mengintegrasikan Telegram Bot API ke dalam sistem web. Fitur ini dirancang untuk memberikan pembaruan informasi instan langsung ke perangkat pengguna, seperti peringatan otomatis pada suatu aktivitas atau pembaruan status layanan. Kemampuan ini memungkinkan terciptanya sistem monitoring yang lebih responsif dan mudah diakses.
